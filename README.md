# Azeroth Atlas — WoW Forever Companion

Interaktive Fan-Website für **WoW Forever** mit Build-Bibliothek, Level-Regler, Talenten, Dungeon-Loot und Farmempfehlungen. Enthält auch persönliche Hybrid-Builds für Druide, Priester, Paladin und Hexenmeister.

## Website

Nach Aktivierung von GitHub Pages erreichbar unter:

**https://derb3rt.github.io/azeroth-atlas/**

Die Website besteht aus einer eigenständigen `index.html` im Hauptverzeichnis. Ein Build-Schritt ist nicht erforderlich.

### GitHub Pages aktivieren

1. Im Repository **Settings → Pages** öffnen.
2. Unter **Build and deployment** die Quelle **Deploy from a branch** wählen.
3. **Branch: main**, Ordner **/(root)** einstellen und **Save** klicken.

Nach der Bereitstellung den Link oben aufrufen.

## Funktionen

- Builds von neun Klassen, inklusive persönlicher Hybrid-Varianten
- Level-Regler und interaktive Talente
- Dungeon- und Lootempfehlungen passend zum Level
- Farmspots für Erfahrung, Gold und Materialien
- Favoriten und persönliche Notizen im Browser gespeichert

Einzelne Loot- und Dungeon-Einträge beruhen auf Classic-Referenzen und sind **nicht automatisch als Forever-bestätigt** zu verstehen. Aktuellere Talentdaten können bei bestehender Internetverbindung aus externen Community-Quellen geladen werden.
